## 真实账户入口（0.9）

打开“账户与钱包 → 添加账户”，也可点击任意页面右上方的“添加账户”。

- 币安：填写名称、HMAC API Key和Secret，仅允许读取权限。凭据交给macOS钥匙串，普通文件和备份不含密钥。首先核对权限，再查询现货、普通U本位及平台返回的资金/Alpha/股票钱包明细。具体范围与限制见本文顶部；当前不是币安全账户总额。
- 钱包：填写一个公开0x地址，选择Ethereum、BSC、Arbitrum、Base、Optimism、Polygon PoS。通常可使用同一普通钱包地址，各网络分开读取。不接触私钥或助记词。
- 当前免费钱包查询已包含代币目录扫描，并新增BTC与Solana；具体网络、价格来源和覆盖边界见本文顶部。
- 手动刷新：每条接入提供修改、刷新、移除和上次成功时间。失败保留旧余额；首次失败显示未读取。未提供的价格保留数量，可从“资产与价格”补价。币安交易流水随统一账户更新读取最近7天，尚待模拟和真实账户验证；完整净收益仍未接入。
- 接入记录与最近余额保存在同目录`connections.json`，仅当前用户可读写；密钥在系统钥匙串，按资料目录隔离。人工备份不包含此文件或钥匙串。更换电脑后需要重新添加账户。移除接入保留原手动成本，但不再计入已移除账户的余额。

## 手动负债和现金余额（0.8）

资产与价格 → 负债管理，可添加房贷、车贷、信用卡欠款及其他借款。填写名称、剩余欠款、人民币/美元和可选备注；支持修改金额、确认结清。结清后金额归零并保留记录，可修改金额重新记入。每次保存沿用本机文件、备份及旧页面覆盖保护。未计算未来利息、月供或还款提醒，不将手动修改当作真实交易。

总览新增总资产、总负债、净资产及按四类分组的负债条形图；欠款大于资产时允许负净资产。负债不进入币种/股票持仓，不改变账户资金占比的分母。添加负债后整体历史提示资料不足，不编造过去的负债曲线。全站货币切换和隐藏同样适用。

资产与价格 → 手动资产 → 资产类别选择现金余额，直接填写人民币或美元余额，无需代码和单价。现金归入现金与稳定币，可在管理列表修改余额；其余资产数量仍不提供编辑。完整持仓、账户和总览可见现金，不混入加密资产或股票分类。人民币仍按固定示例汇率7.12折算。

导出及恢复包含负债；旧文件没有负债字段时按无负债处理，旧备份确认恢复时负债数量会显示0。每类最多200条手动资产/负债，金额有格式及安全范围校验。本轮未写入示例欠款，也未改动本人保存的成本。

## 本机手动资料

资料默认保存在 `~/Library/Application Support/PersonalInvestmentDashboard/workspace.json`，文件权限为仅当前电脑用户可读写。设置中可查看路径。清除浏览器资料后仍读取该文件；使用项目自带的本机服务，单独打开生成的静态网页不提供保存功能。测试可用 `INVESTMENT_DATA_DIR` 指定隔离目录。请勿同时启动多个服务共用同一个资料目录。

首次启动且文件不存在时，自动迁移有效的旧浏览器 `personal-investment-dashboard.workspace.v1` 资料，旧资料仍保留。文件已存在时优先读取文件，发现未迁移的不同旧资料时提示去设置预览核对，不自动覆盖。

每次修改前自动备份到同目录的 `backups`，保留最近20份。导入文件先预览，确认后才替换；恢复前也备份当前资料。损坏文件暂停普通保存，可从设置明确恢复，损坏原件另存保留。支持导出到其他位置，没有云端备份；同机备份不能防止磁盘损坏。不会将手动数量、价格、成本或上传图片发送到外部服务。图片限制为不超过 1 MB 的 PNG、JPEG、WEBP，整份资料不超过12 MB。

保存后总览、市场分类、账户与钱包的当前估值同步更新。手动定价不会被初始示例价格覆盖；恢复初始价时使用原示例或原人工录入价，不表示联网获取行情。小额代币单价保留有效小数。旧版保存的资料仍保留，不因移除页面而清空。

人工补充资产或价格后，受影响的示例历史曲线显示资料不足，避免把新资料编进过去。其他标签页修改资料后，旧页面会阻止覆盖并提示先保留输入再刷新；空间不足或格式异常时保留旧资料并报告错误。

本机目前最多 200 项手动资产，保留最近 500 条手动操作记录；旧版资产照片只保留兼容读取，不再提供新增和对比界面。

来源列表随账户资料生成：交易所汇总旗下账户，每个钱包和券商来源单独列出；添加到手动账户后也会列出该来源。初始 12 个示例账户整理为 10 个来源。未被人工估值改动的示例账户有独立固定走势；没有记录或受人工估值影响时提示历史不足。

## 合约金额规则

交易记录默认进入“全部”，也可切换“合约”：同一账户身份、合约及方向从开仓到全部平仓合为一轮，加仓和分批平仓不重复列结果；单向反手拆成旧轮平仓、新轮开仓，手续费按数量分摊。主卡直接显示平台平仓盈亏、手续费及已平仓量，详情可看均价、数量、持仓时间和逐笔成交。“全部”汇总合约与现货、钱包等记录，原始成交在合约详情中保留。

同步时补读最近7天合约成交，并核对截止时刻的持仓数量。若读取期间发生新成交、资料有缺口或数量不符，该品种暂不确认新轮次；旧记录需要手动再次同步以补齐方向及核对资料。连续同步且历史记录完整时，已确认范围可以延长；不会清空原流水。

页面采用平台平仓盈亏，手续费单列，不再以自行计算的扣费净值替换平台盈亏。缺失数值显示横线，历史保证金缺失时不显示回报率；手续费或资金费不齐不会挡住已有平仓盈亏。资金费有明确归属时在详情中展示，读取范围说明默认收起。完整性校验和原始成交记录仍保留。

本轮仅完成代码与静态核对，未执行模拟测试、浏览器检查或真实账户同步。另行同意模拟测试后可运行 `npm run check:contract-history` 与 `npm run check:transactions`；不会使用真实密钥或账户。

- 币种与股票余额包含已存入的保证金币种；占用保证金不重复相加。
- 总资产 = 资产余额合计 + 合约浮动盈亏；个人净资产 = 总资产 − 未结清负债。账户资金分布仍按账户资产净值计算，不把个人房贷分配给某个交易所。
- 分类卡片和分布图以资产余额合计为基数，合约浮盈亏通过对账条单独说明。
- 同币种、同账户的多空仓位使用不同记录；放大后的仓位金额只作说明，不加入总资产。
- 示例包含两个独立合约账户和一个已有的 Bybit 统一账户；统一账户不复制另一份本金。
- 本轮只演示 USDT 永续；组合保证金示例不虚构单仓保证金、固定杠杆或强平价。保证金合计注明仅包含已提供资料的仓位。
- 正式接入时需根据账户模式核对并采用平台实际净值，不能重复加已包含的盈亏，也不能照搬样稿计算替代平台账目。

## 启动方式

页面运行已在前一轮得到同意；需要重新启动时，在这个文件夹内使用：

```bash
npm run dev -- --port 5173 --strictPort
```

随后打开终端显示的本机地址。服务仅绑定本机，不向外网开放。端口被占用时会停止，不会自动切换到别的地址。

需要在另一台电脑准备依赖时先运行 `npm ci`。开发工具使用的 Node 版本需满足 Vite 的要求，当前安装环境为 Node 25。

# 收益分析的分类与统计范围

收益分析按现货盈亏（加密现货、股票）、合约盈亏、交易手续费、资金费、交易所奖励分开。交易盈亏排行排除返佣、返现、资金费和手续费；只有奖励的 ETHUSDT 不会出现在交易盈亏排行。资金进出统一在交易记录看，链上不参与本页投资收益。

现货采用“期末持仓价值－期初持仓价值＋卖出金额－买入金额”，并核对转入转出、奖励和已扣费用，避免把本金或奖励算成涨价收益。新估值保存数量与账户读取状态，旧历史保持兼容；缺期初资料、缺成交、数量不符、股票来源未接入时明确标注。只查全一个交易对不能证明整个品种的买卖完整，其他交易对范围不足时仅显示已记录部分，不参加完整金额排行。现货连续读取范围保留累计起点。

手续费保留所有原币，并分支出与退回；只有流水自带成交价或可靠的已存奖励历史估值才能折算。USDC、USDT、美元不直接混加。没有历史价格的 BNB 等费用仍会显示，暂不计入统计币种的合计。主金额始终标为已记录部分，不能视为完整净收益。当前未平仓浮盈参考仅在合约复盘展示，本期只取期末浮盈减期初浮盈。

本轮只进行代码检查与构建；模拟用例已补充，须用户单独同意后再运行。没有主动查询真实账户。
