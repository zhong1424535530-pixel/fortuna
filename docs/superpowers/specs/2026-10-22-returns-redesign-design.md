# 收益分析改版

用户已同意 2026-10-22 方案，并授权直接实施。保留深色绿色样式，拆成整体收益、合约复盘；从结果、变化、来源到明细排列，手机纵向显示。

整体收益：时间、来源、投资类别及记录币种筛选；完整净收益/收益率在资料不齐时不计算；展示已记录净收支、奖励、当前持仓浮动盈亏。实际入账曲线、每日收支、分类拆解、资产/账户收支排行、资金进出对账、缺失资料说明。当前浮盈单独标注不受时间筛选，不能冒充区间收益。

合约复盘：复用 buildContractHistory、ContractRoundModal，按平仓日期统计整轮收益。仅已平仓且净收益可确认的同结算币交易进入胜率与盈亏比。展示净收益、胜率、平均盈利/平均亏损、已平仓笔数；每日/累计已平仓净收益、做多做空与品种表现、费用、分页明细及当前持仓。跨期整轮统计明确说明，与整体页的实际入账口径分开。

金额用 Decimal，按原币种合计，不按当前价格追算历史。转账本金、买卖金额不当收益；成交与关联收支重复时只计一次；负手续费作为返还。资料缺失和有记录的零分开。没有事件不补假历史，没有足够样本不显示胜率。全站隐藏金额覆盖数字、曲线与详情。

不增加外部请求、不修改真实账户/持仓/密钥和服务器保存格式。只读已有本机记录。完整现货/股票收益和跨账户外部资金核对尚不具备，明确显示缺口，后续单独补齐。

用户要求修改和模拟测试分开：本轮只编辑并做编译检查；写好最小自检但不运行，待用户明确同意模拟测试。
