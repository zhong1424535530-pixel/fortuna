# 全项目本机资料库方案（用户已同意开发）

## 目标

把本项目实际读取、填写及用于计算的业务资料统一保存，供以后按日期、账户、币种和类型查询。默认不按资料年龄删除历史，不再受交易文件10万条或48MiB的总量上限约束；仍保留单次读取量、内容格式和磁盘空间检查。数据库不能补回平台已不提供、且项目从未取得的历史。

## 选择

使用SQLite，适合本机单人应用，资料库位于现有本机数据目录内，拟命名`portfolio.sqlite`。不增加独立服务器、付费来源或云端上传。将来改成多人或多设备同时使用时再评估服务器数据库，本次不提前建设。

系统钥匙串继续独立保存账户密钥，资料库只保存连接说明与凭证是否存在的标记。头像/币种图标文件继续存放在原素材目录，资料库保存其位置；完整导出包含用户自定义素材。临时网络连接与可重新获取的图片缓存不属于必须永久保存的业务数据。

## 保存范围

| 资料 | 保存内容与规则 |
| --- | --- |
| 账户、钱包 | 名称、来源、公开地址、网络和已有连接配置；沿用原账户身份，不重新添加账户或查询余额 |
| 原始交易及收支 | 逐笔成交、充值提现、钱包收付与兑换、资金费、手续费、奖励；保留原编号、原币数量、来源状态与时间，同一记录更新不重复入账 |
| 人工资料 | 人工账户与资产、成本、负债、自定义价格和图标、原有修改记录 |
| 资产与仓位历史 | 当前已读余额/持仓，以及今后每次实际取得的有效历史采样，带账户身份、来源和时间；不再用旧曲线4000点上限删掉原始采样 |
| 计算依据 | 已有奖励折算价格与时点、今后实际使用的行情与折算依据；市价折算和平台原始到账金额分开保存 |
| 查询进度 | 每个来源读到了哪里、哪些范围完整、哪里失败或缺失，避免重读和伪造完整历史 |

只归档项目真正取得的数据，不收集全市场的每秒行情。已经被旧版本删减的历史采样无法恢复；原始平台记录的合法修正仍按原编号更新。金额保留原有精度，不能因更换保存方式被四舍五入。

## 页面与查询

交易列表改成按需读取当前日期和筛选范围，翻页时再取对应记录；汇总在完整筛选范围计算，不能只统计当前一页。合约整理必须保留跨日期的开仓、加仓和部分平仓上下文，不能因分页或日期过滤把一轮拆错。

资产总览、收益分析、历史曲线、账户及设置页都通过同一资料库读写，保持现有金额口径及页面操作。长期曲线显示可以抽取部分点绘图，但底层原始采样保留。历史页面仍不能把缺失资料当零。

## 迁移与回退

1. 用户确认后先开发保存入口与迁移工具，不直接改写本人现有资料。
2. 准备隔离资料检查：旧文件读取、新旧格式兼容、同编号去重、精确金额、超10万条、跨期合约、分页汇总、并发保存、失败不覆盖、导出恢复。按照用户要求，代码完成后单独请求模拟测试许可。
3. 模拟检查完成后，再单独确认执行本人资料迁移：先完整备份四份旧业务文件与原备份文件，保留图标素材。
4. 在临时资料库中导入已有资料，逐类核对条数、账户身份、最早/最晚时间及原币金额；无效资料报告问题，不静默丢弃，不用空资料替换损坏文件。
5. 核对通过才切换正式读写；失败继续使用原保存方式。旧文件保留，迁移记账确保重复启动不会重复导入。
6. 切换后的新增资料只写入资料库。若以后回退，先导出切换后的新增资料，不能直接退回过时旧文件而丢掉新记录。

迁移不改真实持仓，不发起交易或兑换，不读取或搬运系统钥匙串中的密钥。旧的人工资料备份仍能导入；恢复完整资料库前必须预览并确认影响范围。

## 备份

设置页提供完整业务资料导出/恢复，覆盖账户连接说明、资产、交易、历史、计算依据及自定义素材，明确密钥仍在本机钥匙串。旧的人工资料备份与完整备份应明确区分。

应用运行时每日首次有新资料后创建一致的数据库备份，迁移和恢复前额外备份；默认保留最近30份日备份，不清理正式业务历史。提供手动导出到其他位置，避免同机磁盘损坏使正式库与备份同时丢失。使用数据库提供的安全备份方式，不在写入中直接复制单个文件充当完整备份。

## 完成边界

确认的是数据库与业务保存改造，不自动授权模拟测试或真实资料迁移。代码完成、模拟检查、本人资料迁移分别报告结果。数据库增加的是长期保存和查询能力，不改变交易所可回查期限；网页关闭时持续采集、云端部署、多设备同步及补齐旧账单属于其他任务。

## 当前代码依据

- `server/workspace-store.mjs`：人工资料及仅人工资料备份。
- `server/connection-service.mjs`：连接与当前持仓快照，密钥位于系统钥匙串。
- `server/transaction-store.mjs`与`src/data/transactions.ts`：增量合并原始流水，目前10万条/48MiB上限。
- `server/equity-history.mjs`与`src/data/equity-history.ts`：曲线原始点当前逐步降采样且最多4000点。
- `server/vite-storage-plugin.mjs`：现有本机数据目录和可选路径覆盖。

参考：[SQLite适用场景](https://www.sqlite.org/whentouse.html)、[SQLite安全备份方式](https://www.sqlite.org/backup.html)。本方案仅基于代码与官方文档核查，未访问本人资料、运行模拟或迁移数据。
