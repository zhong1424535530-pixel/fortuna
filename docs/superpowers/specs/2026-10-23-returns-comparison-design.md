# 收益分析周期对比与统一排行（已获用户同意）

默认排行为全部，分加密现货、股票、合约、其他；行内显示类别与账户，不合并不同类别或账户。手动资产列入对应类别，没有完整增减记录时不计算假利润。排行可展开全部，保留组成详情。移除重复现货面板，其入口改为排行。

顶部左侧保留本期已记录净收益，右侧改两期横条与金额差。缺失不能当0，不同资料完整程度不能当完整收益比较。收益率只有净收益、期初本金、资金进出均可核对且期间没有需要加权处理的资金进出时才计算；否则显示横线，原因放入详情。收益率差以百分点表示，不把金额增幅称为百分点。

本月对上月同期，今年对去年同期，短月或闰日按目标月末截断；近7/30天对前7/30天，自选范围对前一个相同日数区间。包含今天时保留相同北京时间截止时刻。全部不设虚构上一期，展示已记录交易收支累计和起止时间，不冒称完整持仓收益曲线。手动选择日期不自动冒充本月或今年。

两期复用同一计算入口与来源、币种筛选。无新数据源、真实账户查询、保存迁移或新增付费依赖。只准备隔离断言和运行静态检查；模拟与浏览器验收须用户另行同意。
