# 总览布局与资产来源选择实施计划

用户已确认本轮方案：顶部取消地球，金额与整体净资产曲线左右排列；下方曲线支持按已添加的交易所、钱包、券商选择；主要持仓改成环形图；详细持仓一览保留。

## 改动范围

- `src/data/portfolio.ts`：账户增加来源归属，动态归并来源与净值；独立示例账户走势；主要持仓前五项加其他的汇总。总净值与资金归属不变。
- `src/components/SourceHistory.tsx`：来源曲线与选择器，电脑为可搜索下拉框、手机为底部抽屉；时间范围独立于顶部整体曲线。
- `src/components/Charts.tsx`：曲线可接收明确的历史点，主要持仓环形图与可点击图例；隐藏金额时移除图表。
- `src/App.tsx`：顶部左右布局、账户数量入口、来源曲线和持仓图接入，保留原持仓一览与详情。
- `src/styles.css`：响应式布局、来源选择弹层和饼图排版；移除废弃地球和排行样式。
- `scripts/check-demo.ts`：补充来源归并、历史终点、不同来源走势、其他资产合计的断言，写好后不执行。
- README、设计文档、实现说明：同步已写入的样稿范围。
