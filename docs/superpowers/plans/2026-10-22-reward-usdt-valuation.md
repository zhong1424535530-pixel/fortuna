# 奖励按记录时点折合USDT

用户明确选择：此前未确认的现货返佣按当时币价计算，USDC和USDT按1:1合并，页面不添加“估算”字样。保留来源状态，不把市价折算当成平台已发放；不改余额，不执行真实兑换。模拟测试仍需另行同意。

- [x] 先在现有隔离脚本准备断言，不执行：历史分钟价格、同币同分钟共享缓存、稳定币1:1、价格缺失/异常跳过、负返还、旧记录重用、保存校验、原币不变、总额只累计折合值。
- [x] `src/data/transaction-rewards.ts`：集中判断可折算奖励及取得折合USDT金额，排除失败/处理中和可能受限的新人奖励。
- [x] `src/data/transactions.ts`：增加可选的rewardValuation（金额、使用价格、行情时间、交易对、折算依据），校验币种、时间与乘法关系；旧记录兼容，原始金额不改。
- [x] `server/reward-valuation.mjs`：复用现有币安公开1分钟行情读取方式，不发送账户凭证。取记录所在分钟的开盘价，优先USDT交易对，备选USDC交易对按1:1；不以当前价或日初价代替。结果随原流水保存以便复用；每轮最多64次公开请求，失败保留原记录，缺价不按零。
- [x] `server/binance-transactions.mjs`：复用当前账户范围及已有190秒/220次总预算，在近期记录读取后补奖励折算，自动账户更新继续补齐。仅更新奖励元数据；历史资金费等其他读取逻辑保留。
- [x] `src/data/transaction-summary.ts`：奖励统一累加折合USDT，已读到的现货返佣也参与；无价格的非稳定币跳过。金额缺失不显示“已确认”。其他四项继续按原币种。
- [x] 交易卡显示折合USDT，详情保留原币数量及使用的行情、时点；原始到账状态不变。奖励汇总取消“已确认”标签，名称保持“奖励”，只显示USDT。
- [x] 同步README及此前说明，静态检查/构建和独立只读审查，不执行断言、浏览器验收、真实账户查询。

限制：现货返佣查询只提供更新时间，因此按该记录时间所在分钟折合，不保证与平台兑换时刻/汇率一致；USDC按1:1为用户指定的近似规则。未知币、无交易对或缺历史成交时不折算。原币返佣明细与未来若接入的发放记录不能再次相加；本轮不新增发放数据来源。
