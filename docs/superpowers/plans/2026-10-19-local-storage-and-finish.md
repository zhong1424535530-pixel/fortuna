# 收尾核对与本机文件保存

本人已明确要求直接完成原计划第一、二步；本轮允许先改代码再做模拟检查。第三步真实账户读取不在本轮冒充完成，密钥不写入聊天、浏览器保存资料或备份。

## 方案与范围

使用现有本地网页服务承接资料保存，不额外安装数据库或开放外网端口。默认目录为 ~/Library/Application Support/PersonalInvestmentDashboard，允许测试使用独立临时目录。保持现有页面、成本计算和浏览器旧资料。

- [x] 集中运行现有金额自检，并在独立浏览器检查成本、盈亏、账户筛选、图表时间、隐藏、手机排版。
- [x] 分离可共用的资料类型/校验；所有保存改为等待本机文件确认后再报告成功，服务不可用时只读并保留输入。
- [x] 本机资料文件使用独立版本号、临时文件写入后替换、修改前备份及最近20份保留；并发旧页面拒绝覆盖；损坏文件不自动清空。
- [x] 利用 Vite 现有本机服务挂载资料接口，绑定回环地址，校验Host/Origin/自定义请求头、体积/资料格式与资产账户语义；不收集密钥。
- [x] 启动时读取文件；没有文件时自动迁移有效旧浏览器资料。文件与未迁移旧资料冲突时不自动覆盖，设置页可预览恢复，保留浏览器旧资料。
- [x] 设置页展示保存位置和状态，支持导出备份、文件导入预览、明确确认恢复，以及自动备份预览/恢复。恢复前同样备份当前资料。
- [x] 使用临时文件夹覆盖持久化、冲突、损坏、备份恢复、非法资料、接口跨站防护等小型断言；生产资料与测试隔离。
- [x] 重启本机网页服务并迁移用户当前示例资料，确认文件保存结果；完成功能和手机显示回测，保留报告与截图。
- [x] 同步文档和真实接入边界。暂不接入API、不索要密钥，不把样稿当真实账户。

主要风险保护：写入失败不清空输入；旧标签拒绝覆盖；迁移前保留旧资料；恢复前备份；自动备份在同一电脑，不等于异地备份。所有测试使用专门目录，不能清空用户浏览器和真实保存目录。
