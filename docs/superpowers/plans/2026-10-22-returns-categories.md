# 收益分析分类优化实施计划

用户已确认五类收益及费用、交易盈亏排行、移除资金进出对账；本轮在原目录执行，不创建分支或新任务。

## 范围与约定

- 整体收益：加密现货、股票、合约交易盈亏、手续费、资金费、交易所奖励。奖励不进入交易排行；链上只在交易记录看进出。
- 现货公式：期末市值－期初市值＋卖出金额－买入金额－转入价值＋转出价值。为将手续费与奖励单列，还原持仓中已扣的费用、扣除收到的奖励价值。
- 合约：本期已实现盈亏与持仓浮盈变化分开，整轮复盘继续使用原有逻辑，不把整轮历史收益替代本期收益。
- 原币种保留，已存奖励历史估值可以复用。缺少历史价格的手续费显示原币，不使用现价回算历史。
- 完整本期净收益不能确认时显示已记录部分及缺项，不能把缺项当零。无记录与已核对为零不同。
- 旧估值没有数量及读取状态，不能据此编造期初持仓；新估值增加可核对信息，兼容保留旧记录。股票成交和分红来源未接入时明确提示。

## 验收重点

ETH 只有返佣时不出现在交易盈亏排行；USDT 筛选不会使 BNB 手续费消失；任何不完整合计明确标为部分；新资产记录可支持期中减仓加仓的计算；旧数据和真实账户不被修改。
