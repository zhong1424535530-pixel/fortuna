# 分类导航与详细页面实施计划

用户已批准七个一级入口：资产总览；资产（点击展开加密资产、A股、美股，首次加密资产）；账户与钱包；交易记录；资产历史；收益分析；资产与价格。设置留在底部，原完整持仓成为总览内的详细入口，合约不再单独占侧栏。

沿用 React、ECharts、现有 UI 和固定示例。新页面不连接真实账户、不编造交易和投资收益。手动资产、人工价格、图标与资产快照只保存在当前浏览器；统一进入原有汇总。未知价格保留数量并显示待估值，不伪装成零资产；历史快照保存当时的数量和价格，不随日后改价重写。原始固定示例保持可追溯，所有人工操作注明本机资料。

## 执行与核对

按现有技能的分工与审查流程，账户页、记录收益页和手动管理页可独立实现；核心资料与导航由主代理整合。项目没有 Git 仓库，不创建分支、提交或发布。仅静态核对调用、隐私遮盖、金额去重与输入边界。程序模拟测试始终留待用户明确同意。
