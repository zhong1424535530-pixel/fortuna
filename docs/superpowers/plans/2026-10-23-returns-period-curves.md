# 两期累计净收益曲线实施计划

**目标：** 将收益总览右侧柱状图换成按周期第几天对齐的两条累计净收益曲线。

**范围：** 复用已有收益计算、历史估值和图表组件；只读取本机资料，不查询真实账户，不写入模拟账目。

- [x] `src/data/returns-curve.ts`：从真实日末附近的估值记录计算累计净收益，沿用整期完整性校验；缺日保留空白。
- [x] `src/data/returns-preview.ts`：独立提供虚构的逐日持仓盈亏及已有模拟收支，保证两期末端与模拟总览一致。
- [x] `src/components/Charts.tsx`：本期绿实线，上期浅蓝虚线；显示周期日序、末端金额和日期提示；断点不补线。
- [x] `src/components/ReturnsPage.tsx`、`src/returns-page.css`：替换旧柱图并扩大曲线区域，保留金额、涨跌幅及隐藏金额功能。
- [x] `scripts/check-returns-curve.mjs`：补充纯内存用例，覆盖缺日、充值、期末一致、币种缺价、来源筛选和旧记录。
- [x] 仅运行代码检查与打包。模拟测试和页面操作按用户要求留待单独同意后进行。

**边界：** 曲线没有逐日历史时不根据最终金额倒画；末端采用同口径总览的可比金额。较短的上一期不延长到不存在的日期。全部时间继续显示原来的累计交易收支走势。
