# 合约复盘手续费换算

用户已确认：已有平仓盈亏、原币手续费分别展示；BNB按扣费当时价格换算，再计算净收益。普通缺资料不追加提醒图标。

1. 给原始交易增加可选的手续费历史报价依据，校验币种、分钟、交易对和正数价格；保留原始手续费数量。
2. 复用已有历史分钟价格校验，按币种和时间段补查公开报价，缓存已查结果。补查入口仅处理已存流水，不访问密钥或刷新账户。
3. 在现有本机保存与交易加载流程中传递报价依据；后续同步保留相同交易已有的报价，异步补查期间不覆盖新记录。
4. 每笔合约分别汇总成交盈亏、原币手续费、折算手续费和资金费。只有完整、可核对的交易生成最终净收益。
5. 平仓盈亏、费用、资金费分别汇总已有数据；多空按全部已平仓笔数统计；胜率及平均盈亏按已核对净收益统计。
6. 收益页复用换算结果，未换算完成时展示原币手续费，避免USDT零额掩盖BNB支出。
7. 补充虚构记录检查脚本，覆盖跨币种手续费、反向开仓分摊、缺历史价格、数据保存与独立统计。依用户要求，本轮只写检查，不执行模拟；仅运行代码检查、打包及脚本语法检查。

边界：不把缺少的资金费当零，不用当前持仓浮盈代替历史平仓收益，不按现价估算历史费用，不更改原始交易金额或账户持仓。


## 实施结果

- 新增 `src/data/fee-valuation.ts` 作为历史费用换算与依据校验的共用入口；交易原币金额保持原样。
- 新增 `server/fee-valuation.mjs`，复用奖励模块的分钟K线校验，批量补查公开历史报价；报价随原交易保存，后续同步保留有效依据。
- 收益页先读取本机数据，再补查尚缺的历史费用报价；页面可见时每分钟继续补齐，单轮最多32次请求，45秒后不再发起新请求。
- 合约整理按各成交发生时价格换算并分摊反手手续费；统计分项独立，多空按全部已平仓笔数计算。
- 未换算完成时展示原币费用；完整净收益只使用可核对部分，缺失资金费不补零。
- 已补充虚构记录的检查内容，含历史价格校验、缓存、正常同步保留依据、反手分摊和异步补价期间发生交易更新；这些模拟检查尚未运行。
- 代码检查、打包与修改过的服务脚本语法检查已通过。未手动刷新真实账户、读取密钥或执行模拟测试；实际历史补价结果与页面效果待后续验证。
