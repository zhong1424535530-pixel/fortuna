# 全局60秒行情更新实施计划

> For agentic workers: use superpowers:executing-plans in this session. User approved implementation; simulated tests require separate approval.

**Goal:** 页面打开时每60秒更新已接入资产现价，全站共享；补齐可识别币种日初价，不重复扫描账户余额。

**Architecture:** 新增独立行情读取及价格更新入口，读取现有持仓后只改价格、估值和日初参考价。前端只启动一个计时器，已有资料变化事件驱动所有页面和打开的详情重算；手动定价继续优先。

**Tech Stack:** 已安装React、TypeScript、Node、CCXT、decimal.js及公开行情来源，不新增依赖。

- [x] 准备断言（暂不执行）：价格更新不改数量及账户时间；金额重算、失败保留、无价/异常拒绝、并发账户移除不覆盖、同一行情请求合并及60秒定时。成本资料未改动；弹窗保持通过源码核对，浏览器模拟待授权。
- [x] `server/market-prices.mjs`读取现有各平台公开现货及合约标记报价，钱包复用`walletPrices`，股票复用币安股票报价。只处理有明确身份的已有持仓，初始余额及手动资料不发送到行情来源。
- [x] `daily-prices.mjs`在现有日初查询中为币安币种补充北京时间零点K线，USDT当日美元参考价独立获取，校验开盘时间与交易量；成功按天缓存，失败下一轮重试，小额跳过。
- [x] `connection-service.mjs`新增行情刷新，短时限频、合并请求；请求完成后重新读取文件，期间账户有变化则丢弃旧结果。保留数量、账户读取时间与平台报告的合约浮盈亏，更新报价及持仓金额。`workspace-api.mjs`新增同源受保护入口，不放开账户读取或交易权限。
- [x] `live-types.ts`、`portfolio.ts`支持独立价格时间，`daily-pnl.ts`以最新行情时间判断当天价格有效性，不冒充余额已刷新；无日初参考价仍按本人要求记0。
- [x] `live.ts`及`App.tsx`启动全局60秒计时器，禁止请求重叠，错误保留旧值；安静更新全站及详情，保留筛选和输入，不每分钟弹成功提示。
- [x] 说明代码生效范围：程序打开时生效，免费行情可能延迟；人工价格不自动改，余额及平台报告的合约浮盈亏仍以账户刷新为准；股票历史行情另行接入。
- [x] 类型检查、脚本语法核对和构建后停止；不运行模拟测试、不主动刷新本人真实账户。

约束：优先使用现有实现；日初与额外报价只补不小于1美元的资产；失败不清零、不删除持仓。现货价格不可替代合约标记价格。报价保存不得触发人工资料备份或成本编辑记录。

只读代码审查完成并修复：多账户混用旧估值、成本弹窗旧对象、钱包代币错误继承所在链原生币报价。增加相应断言但未执行。定时更新绕过旧缓存，报价来源超过5分钟则不采纳；主流币保存来源价格时间。

最终静态核对：`npm run build`通过（保留已有大文件提示）；6个服务文件、前端行情模块及两份断言脚本的`node --check`通过。没有运行模拟断言、浏览器检查或主动账户同步。新代码启用后页面会按规则自动查询市场行情，真实运行表现待用户另行授权验证。
